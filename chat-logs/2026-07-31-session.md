## Technical Details

### Register Detection Issue
- **Root cause**: Sequential optimizer uses fixed `n_register=1` for closed-top
- **Problem**: For bores > 1000mm, fundamental resonates at register 2 in TMM
- **Auto-detection formula**: `k_est = (4.0 * L_est * fundamental / c + 1.0) / 2.0`
- **Current workaround**: Pass `n_register=2` explicitly for contra instruments
- **Not fully solved**: Per-fingering register detection needed during refinement
