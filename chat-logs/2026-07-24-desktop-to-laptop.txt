## Architecture Redesign (Branch: refactor/architecture-redesign)

We started a major architecture redesign following ChatGPT's recommendations.
This branch restructures the codebase into a modular, instrument-agnostic platform.

### Key Design Decisions

1. **Solver-agnostic**: The solver does NOT know if it's solving a clarinet or trumpet.
   It receives an AcousticNetwork graph and solves it.

2. **CoordinateTransform module**: All coordinate conversions go through one place.
   No code outside that module converts coordinates.

3. **Physics plugins**: Each physical effect (propagation, junction, tonehole, radiation, losses, excitation)
   is a separate plugin with an abstract interface. TMM and FEM implement the same interface.

4. **Instrument builders**: ClarinetBuilder, BassClarinetBuilder, BrassBuilder all produce
   AcousticNetwork objects. The solver processes them identically.

5. **Property tests**: Verify coordinate inverses, analytical tube solutions, etc.

   ```python
   from backend.core.network import AcousticNetwork, Segment, Boundary, NodeType, BoundaryType, ExcitationType
   from backend.solvers.tmm_solver import TMMSolver
   
   net = AcousticNetwork(
       segments=[Segment(length=1200, radius_in=12.5, radius_out=12.5)],
       ports=[],
       boundary_reed=Boundary(type=BoundaryType.REED, excitation=ExcitationType.REED),
       boundary_bell=Boundary(type=BoundaryType.BELL, position=1200),
   )
   solver = TMMSolver()
   wl = solver.find_resonance(net, 4675.0, [], n_register=1)
   print(f"Fundamental: {343200/wl:.1f} Hz (expected ~71.5 Hz)")
   ```
