# Session 2026-07-26_2244 — JAX TMM Comprehensive Benchmark

## Summary
Built and ran comprehensive JAX TMM benchmark on `experiment/ai-tier1` branch.
Verified correctness, measured performance, tested optimization approaches.

## Key Results

### Correctness: PASS
- JAX matches Python TMM exactly (0 delta for 12 test cases)
- Action-based approach: pre-built Python actions → JAX walks them
- Verified for closed and open fingerings across 6 frequencies

### Performance
- JAX single eval: 0.017ms (1.3x vs Python 0.021ms)
- Vmap batch=1000: 0.0004ms/eval = **2.7M evals/sec** (52x vs Python single)
- Key insight: batch vmap is the real win, not single-eval speedup

### Optimization
- Gradient descent: stuck at cost=0.115 (floor ops break gradient flow)
- CMA-ES: 5/5 converge to 0.000 (~700ms, ~2500 evals)
- CMA-ES + vmap: total pipeline ~1ms for full optimization

### Critical Findings
1. `JAX_ENABLE_X64=1` required — float32 loses precision in tan/arctan chain
2. `jnp.floor()` in junction2 creates gradient discontinuities → gradient methods fail
3. CMA-ES is the right optimizer for this problem (derivative-free, population-based)
4. Pre-built action arrays enable exact JAX/Python match without reimplementing Profile/cone-stepping
