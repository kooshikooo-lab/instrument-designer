# Session 2026-07-26_2315 — JAX Optimizer Integration

## Summary
Built and tested JAX-powered bore optimizer on `experiment/ai-tier1` branch.

## Critical Flaw Found & Fixed
The original CMA-ES optimizer tried to solve an 18D global optimization problem from random initialization — impossible to converge in any reasonable number of evals. Rewrote to match `benchmark_all.py sequential_refined`'s proven approach:
1. **Sequential hole placement** — smart initialization (each hole placed by brute-force grid search)
2. **DE global re-optimization** — for open-open instruments (sequential placement creates large gaps)
3. **4-stage L-BFGS-B refinement** — bore length → bore radii → holes+diameters → simultaneous
